# Contact

## Course removal

If you represent a golf course and would prefer not to be included, email
**📧 info@lucasgreenbook.org** — no reason needed. How it works, and how long it takes:
**[lucasgreenbook.org/removal](https://lucasgreenbook.org/removal)**

## Copyright, trademark, or a correction

Same address: **📧 info@lucasgreenbook.org**

Please don't open a public issue for anything sensitive — email first and we'll respond.

## Data sources

Every book is built from open data only — OpenStreetMap (ODbL 1.0), public‑domain USGS 3DEP LiDAR,
public‑domain USDA NAIP, and published scorecard facts. See [`legal/`](legal/).
