# Lucas Green Book — Data Sources, Licenses & Legal Records

This folder is the project's **data provenance and clearance record**: every open source each book is built from, the license that source carries, the exact attribution notices used, and our conformance analysis under the Rules of Golf.

Its purpose: if anyone asks *"where did this data come from?"*, this folder documents, source by source, that every distributed book is built only from **open** and **public-domain** data plus **facts**, independently created.

## One-Line Verdict
**All fifteen distributed courses are built entirely from open and public-domain sources.**

- **Hole & green vector geometry:** OpenStreetMap contributors (ODbL 1.0)
- **Slope, contours, arrows & elevation:** Computed by us from public-domain USGS 3DEP LiDAR point clouds (17 U.S.C. §105)
- **Par, yardages, handicap, ratings & slope:** Uncopyrightable facts transcribed from published scorecards and verified against the USGA National Course Rating Database
- **Aerial reference (where OSM lacked features):** Traced from public-domain USDA NAIP imagery (vector coordinates only; no photographic imagery embedded)

**No commercial green-reading product's data, imagery, artwork, symbol set, layout, or trade dress is used, copied, or referenced. No Google, Apple, Esri, Maxar, or Bing imagery appears anywhere in any book.**

> **Not legal advice.** This folder records what the project did and where every input came from. It states no legal conclusion, and none of it was written by a lawyer. Anyone using the same sources should reach their own conclusion.
