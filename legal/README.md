# Lucas Green Book — data sources &amp; licences

This folder is the project's **data‑provenance record**: every source a book is built from, the
licence that source carries, and the exact attribution notices used.

| File | What it covers |
|---|---|
| `01_DATA_SOURCES_AND_LICENSES.md` | Every data source, its licence, and how this project complies |
| `02_ATTRIBUTIONS.md` | The exact attribution notices printed and published |

## Summary
Every book is built only from OpenStreetMap geometry (ODbL 1.0), slope computed by this project from
public‑domain USGS 3DEP LiDAR, **facts** from the published scorecard, and public‑domain USDA NAIP
where an aerial or an unmapped green was needed.

No commercial green‑reading product's data, imagery, artwork, layout or trade dress is used, copied or
referenced, and the project contains **no Esri/Maxar, Google, Apple or Bing imagery anywhere**.

> **Not legal advice.** This folder records what the project did and where every input came from. It
> states no legal conclusion, and none of it was written by a lawyer. Anyone using the same sources
> should reach their own.
